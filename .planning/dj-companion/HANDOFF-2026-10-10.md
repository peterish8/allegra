## What was built this session

### DJ page (`/dj`), `apps/web/src/components/DjPage.tsx`
- **Layout:** the DJ is the main character. Wide screens: stage left (~70%), slim "Coming up" column
  right. The old site top bar is hidden on `/dj`.
- **One piece of glass:** the stage flows into a console tab below it with long S-curves
  (`lib/djStageShape.ts` builds the SVG path; `components/dj/useDjStageShape.ts` measures and sets
  `clip-path` + draws the edge). On phones it is a plain rounded card.
- **Console tab:** prompt bar (sparkle, input, mic, send), then one compact row: Mix/Playlist +
  energy dots as a single dial (`DjSessionChips.tsx`) and 2 starter ideas.
- **Corner tools (top right of stage):** "Hey DJ" ear, settings gear, search icon (the app's
  `CommandPalette` in `variant="icon"`, passed in as `searchSlot` from `App.tsx`).
- **Info "i" (top left of stage):** 9-slide walkthrough acted out by the mascot,
  `components/dj/DjTour.tsx` (built on the site's `InfoTour`; scene helpers now exported from
  `infoScenes.tsx`).
- **Caption:** the DJ's words, centred under the mascot (`DjBubble.tsx`), with action buttons
  (first-run choice, Undo, Start this set, voice download, mic Try again).
- **Queue box:** `DjCrate.tsx` with `DjNowPlaying.tsx` as its lead row (song colours, live level bars).

### Mascot, `components/dj/DjMascot.tsx` + `useDjMascot.ts` + `lib/djMascotMotion.ts`
- Glass sphere with the song's colours swirling inside, highlight on top, shade below, soft drop
  shadow, pill eyes, blush cheeks, a small round-capped smile (SVG) that changes only with mood.
- Motion is one rAF loop writing CSS variables (`--dj-nod`, `--dj-sway`, `--dj-look-x/y`,
  `--dj-blink`, …). It **nods on the beat** (no singing), drifts on a figure-of-eight, follows the
  pointer, blinks, hops for joy, shakes its head on errors. Reduced motion: opacity only.
- Old `djHop.ts`, `useDjRoam.ts`, `useDjPulse.ts`, `dj-mascot.css` were deleted.

### The DJ controls the app, `lib/djActions.ts` (+ tests) and `runDjAction` in `App.tsx`
"play X", "play X and start karaoke" / "sing X", "play my <playlist>", "play my liked songs",
"queue X", "play X next", "like this", "pause/skip/back/play it again", "start/stop karaoke",
"show lyrics", "shuffle on/off", "open library/settings/…", "what's playing?". Anything else goes to
the model as before (no API contract change for this). Karaoke for a just-started song waits in
`karaokeForRef` until that song has loaded. Undo after a set replaces the queue (`djUndoRef`).

### Voice, `hooks/useDjVoice.ts` (app-wide, `DjVoiceContext`)
Three parts, each free-or-your-key, chosen in the settings sheet (`components/dj/DjSettingsSheet.tsx`):

| Part | Free | Your key |
|---|---|---|
| Thinks | on-device Qwen3 0.6B (`lib/djLocal.ts`, existing) | OpenAI / OpenRouter / Gemini (existing `/api/ai/dj/turn`) |
| Hears | browser Web Speech (on-device in Chrome 142+ after its language pack), or Moonshine base q8 ~63 MB on device (`lib/djWhisper.ts`, falls back to Whisper tiny.en) | OpenAI (`gpt-transcribe`) / Groq (`whisper-large-v3-turbo`) via **new** `POST /api/ai/dj/transcribe` |
| Speaks | browser speechSynthesis, or Kokoro-82M q8 ~92 MB on device (`lib/djLocalSpeech.ts`, package `kokoro-js`) | OpenAI (`gpt-4o-mini-tts`) / ElevenLabs via **new** `POST /api/ai/dj/speak` |

- Opera and Brave expose Web Speech without a service; they go straight to on-device listening.
- Mic capture + voice-activity detection: `lib/djSpeechCapture.ts` (+ tests).
- "Hey DJ" wake phrase only with on-device recognition (Chrome on-device, or Moonshine over short
  utterances < 4.5 s), pauses while the tab is hidden.
- Microphone permission: reads `navigator.permissions`, explains the browser's Allow prompt, gives
  unblock steps and a Try again button, and says when the page is not secure (http on a LAN IP).
- Spoken replies duck the music to 30% (`onVoiceDuck` in App.tsx).
- API: `apps/api/src/routes/djVoice.ts`, mounted in `app.ts` with its own 1 MB JSON limit for
  `/api/ai/dj/transcribe`; supertests in `apps/api/src/app.djVoice.test.ts`; contract written in
  `docs/api-contract.md`.
