  <action>
Module doc: what the tally is, that the API calls it with the server secret (like profiles.ts),
and that every write is safe to repeat.

Shared validator: `const snapshot = v.object({ ref: v.string(), title: v.string(), artist: v.string(), album: v.optional(v.string()), artwork: v.string(), duration: v.number() });`

Helpers (not exported): `meta(ctx, userId)` (read or insert `{ songCount: 0, updatedAt: now }`),
`rowOf(ctx, userId, identity)` via `by_userId_and_identity` + `.unique()`,
`evictIfOver(ctx, userId, metaDoc)`: while `songCount > TALLY_MAX_SONGS`, read
`by_userId_and_score` ascending `.take(1)`, delete, decrement (loop at most 5 times),
`addToRow(ctx, userId, song, amount, atMs, mark?)`: insert or patch per §4.3; delete when the
new score is 0; returns nothing. `mark` may set `likeBonusAt`; on unlike subtract the stored bonus
with `addDecayed(score, -10, likeBonusAt)` before clearing it, not at the unlike timestamp.

Exports (all `mutation`/`query` with `secret: v.string()` first, `requireSecret` first line):
- `record` args `{ secret, userId, song: snapshot, secondsHeard: v.number(), playedAt: v.number() }`:
  clamp `playedAt` to `Math.min(playedAt, Date.now())`; ignore if older than 30 days; identity =
  `identityKey(song.title, song.artist)`; if row has playedAt in `recentListens` → return
  `{ applied: false }`; else add `listenAmount(secondsHeard, song.duration)` at playedAt and push
  playedAt (keep last 8); return `{ applied: true }`.
- `bonus` args `{ secret, userId, song, kind: v.union(v.literal('like'), v.literal('unlike'), v.literal('playlistAdd')), at: v.number() }`:
  like: if row.likeBonus → no-op, else +10 at `at`, likeBonus true and likeBonusAt = `at` (create row if absent).
  unlike: if row?.likeBonus → subtract −10 at the stored likeBonusAt, then clear both likeBonus and
  likeBonusAt; else no-op. playlistAdd: +5.
- `seed` args `{ secret, userId, likes: v.array(v.object({ song: snapshot, at: v.number() })), items: same, recents: same }`:
  if meta.seededAt → return; validate each array length ≤ 200 / 300 / 25 (throw otherwise);
  apply +10 / +5 / +3 at each `at`; set seededAt.
- `top` (query) args `{ secret, userId, limit: v.number() }` → up to `min(limit, 200)` rows by
  `by_userId_and_score` `.order('desc')`, returned as
  `{ identity, ref, title, artist, artwork, duration, score }`.
- `clear` args `{ secret, userId }`: delete up to 200 rows; if 200 were deleted schedule
  `internal.taste.clearRest`; else delete tasteMeta. `clearRest` (internalMutation) does the same.
Never `.collect()`. No Date.now() inside the query.
