`getArtist(key)` in try/catch (any failure → fallback facts, cached with `missTtl`; note that

`cache.set(key, fallback, missTtl)` yourself inside load and return it). A 4-slot limiter;
`Promise.race` against the budget: when it expires, fill every unfinished key with the fallback
(without caching it) and return. Tests: popularity maths at 0, 10 k, 10 M followers; language
majority with ties broken alphabetically; similar capped and keyed with `artistKey`; cache hit;
failure fallback cached; budget expiry returns fallbacks; concurrency ≤ 4.
