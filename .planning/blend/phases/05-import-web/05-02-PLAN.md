  <action>
`npm install fflate --workspace apps/web` from the repo root (never inside apps/web; one lockfile).

```ts
export const IMPORT_FILE_LIMITS = { entryBytes: 20 * 1024 * 1024, archiveBytes: 200 * 1024 * 1024, csvBytes: 20 * 1024 * 1024 } as const;
export type ReadError = 'too_large' | 'unreadable' | 'empty';
export async function readImportFile(file: Blob & { name: string }): Promise<{ bundle: ImportBundle; fileHash: string } | { error: ReadError }>;
```

- Hash: `crypto.subtle.digest('SHA-256', await file.arrayBuffer())` → hex.
- `.zip`: reject `file.size > archiveBytes`. `unzipSync(bytes, { filter: (f) => wanted(f.name) && f.originalSize <= entryBytes })`;
  if any wanted entry has `originalSize > entryBytes` → `too_large` (detect in the filter by
  recording it). `wanted(name)` = basename matches the README's library file name or
  `/^Playlist\d+\.json$/`. Decode with `TextDecoder('utf-8')`, `JSON.parse` in try/catch →
  `unreadable`; pass to `bundleFromSpotifyFiles`.
- `.json`: same as one ZIP entry. `.csv`: size check, `text()`, `parseCsv`.
- No wanted entries or zero tracks → `empty`.
Tests (vitest/jsdom or node, whichever apps/web tests use): fixture zip equals direct parse;
a crafted zip with a declared 25 MB entry → `too_large` and the inflate function is never called
for it (spy via the filter); junk-only zip → `empty`; invalid JSON → `unreadable`; CSV fixture.
  </action>
