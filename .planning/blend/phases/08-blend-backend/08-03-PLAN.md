```ts
export const BLEND_BUILD = { budgetMs: 8000, factsBudgetMs: 3000, factsPerMember: 30, discoverySeeds: 3, playCountLookups: 20 } as const;
export class BlendBuildService {
  constructor(deps: { blends: BlendStore; tally: TasteTally; library: LibraryStore; users: UserStore; facts: ArtistFactsService; catalog: CatalogService; resolver: ImportMatcher; now?: () => number; log?: (fields: Record<string, number>) => void });
  detailFor(blendId: string, viewerId: string): Promise<BlendDetail | null>;
}
```
`detailFor`: `get` → null if not a member. `todayUtc = new Date(now).toISOString().slice(0, 10)`.
If `builtFor === todayUtc && !stale` → shape stored data. Else build:
1. Per member in parallel: profile (learning = `isPersonalised`), `tally.top(200)` when learning
   (weights via `currentWeight(score, now)`), `recentLikes(1000)`, `recentItems(300)`.
2. Identities with only a Gaana ref: resolve via `resolver.match` (title + artist) → Saavn
   snapshot or drop; count drops.
3. Top 30 artists per member by a provisional `q` (call `memberTaste` with empty facts first),
   `facts.facts(keys, 3000)`; then final `memberTaste` with facts.
4. `pairMatch` for every pair; discovery = `catalog.getSuggestions(saavnId, 20)` for the top 3
   shared identities (by min p) inside the remaining budget, each in try/catch.
5. `buildBlend` with seed `${blendId}:${todayUtc}` and `previous` = stored previousTracks.
6. Pairs only: `togetherSong` with play counts from `catalog.getSongs` for the 20 best candidates
   (try/catch → empty map); gifts both ways.
7. `saveBuild({ expectedVersion: blend.buildVersion, ... })`; if `saved: false`, re-read and
   shape stored data.
8. Stories per viewer via `storiesFor` when shaping (cheap, not stored).
9. `log({ members, candidates, unresolved, tracks, ms })`: numbers only.
Wrap the whole build in a deadline of `budgetMs`; on expiry use whatever finished (facts
fallbacks, no discovery). Tests with fakes: every frontmatter truth; the concurrency test runs two
`detailFor` calls at once against a MemoryBlendStore whose saveBuild enforces the version.
Route GET `/api/blends/:id` now calls `detailFor`.
