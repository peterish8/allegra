<task type="auto" tdd="true">
  <name>Task 2: convex/blends.ts</name>
  <files>convex/blends.ts, convex/crons.ts</files>
  <read_first>convex/shares.ts, convex/profiles.ts requireSecret</read_first>
  <action>
All public functions take `secret` first and call `requireSecret`. `userId` comes from the API,
which has already authenticated the caller (same model as `profiles`/`library`; module doc says so).
- `create({ secret, userId, displayName, name, consent, code })`: count the user's memberships
  (`by_userId_and_joinedAt`, `take(BLEND_MAX_PER_USER + 1)`) → 'limit'; insert blend
  (`memberCount: 1, buildVersion: 0, stale: true, tracks: [], pairs: [], previousPairs: [], previousTracks: []`),
  member, invite (code passed in from the API's `randomCode(12)`, `expiresAt = now + 7 days`).
  Returns `{ blendId, code, expiresAt }`.
- `get({ secret, blendId, userId })`: blend + members (`take(6)`) when the user is a member, else
  `null` (the API maps null to notfound).
- `listForUser({ secret, userId })`: memberships `take(20)` → blends summary
  `{ blendId, name, memberCount, builtFor, members: { userId, displayName }[] }`.
- `invite({ secret, blendId, userId, code, regenerate })`: member check; live unexpired invite
  reused unless `regenerate`, then old ones get `expiresAt = now`.
- `preview({ secret, code })`: `{ status: 'ok', blendId, inviterName, memberCount, full }` or
  `{ status: 'notfound' }` for unknown, malformed (not 12 chars of the alphabet) or expired codes.
- `join({ secret, code, userId, displayName, consent })`: invite valid → member exists? return;
  full → 'full'; user limit → 'limit'; insert member, `memberCount + 1`, `stale: true`.
- `leave({ secret, blendId, userId })`: delete membership; if none left delete blend, members,
  invites (`take(50)` each); else `memberCount - 1`, `stale: true`, owner hand-over.
- `rename({ secret, blendId, userId, name })`: owner only; 1–60 chars trimmed → 'invalid'.
- `saveBuild({ secret, blendId, expectedVersion, builtFor, tracks, pairs })`: if
  `blend.buildVersion !== expectedVersion` → `{ saved: false }`; else move `pairs` to
  `previousPairs`, keep the identities of the last two builds in `previousTracks` (≤ 100), write
  the new build, `buildVersion + 1`, `stale: false`; `{ saved: true }`.
- `sweep` (internalMutation): expired invites `by_expiresAt` `take(200)`; blends with
  `memberCount < 2` older than 7 days (an unaccepted invite) deleted with members and invites;
  reschedule on full batches. Cron: daily.
  </action>
